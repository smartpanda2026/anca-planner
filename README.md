# ANCA Vasculitis Treatment Planner

A comprehensive, evidence-based treatment planning tool for ANCA-associated vasculitis.

## Features

- 🧬 **AKRiS Risk Calculator** (Bate et al. JASN 2024) with SI units
- 💊 **Multi-protocol treatment planning**:
  - Rituximab + Cyclophosphamide
  - Rituximab alone
  - Cyclophosphamide alone (age/eGFR adjusted)
- 📊 **Interactive Charts**:
  - Treatment timeline with distinct markers
  - Prednisone taper visualization
  - Predicted eGFR trajectory
- 📈 **PEXIVAS prednisone taper** (weight-based dosing)
- 🛡️ **Risk-stratified maintenance** (MAINRITSAN protocol)
- 📱 **Responsive design** for mobile/tablet use
- 🖨️ **Print-friendly** reports

## Evidence Base

- KDIGO 2024 ANCA Guidelines
- PEXIVAS Trial (NEJM 2020)
- ADVOCATE Trial (NEJM 2021)
- MAINRITSAN Trial (NEJM 2014)
- AKRiS Score (Bate et al. JASN 2024)

## Usage

1. Visit [https://YOUR_USERNAME.github.io/anca-planner](https://YOUR_USERNAME.github.io/anca-planner)
2. Enter patient demographics and lab values
3. Calculate AKRiS score (optional)
4. Select treatment protocol
5. Generate and review treatment plan
6. Print or save as PDF

## Local Development

Simply open `index.html` in a web browser. No server required!
